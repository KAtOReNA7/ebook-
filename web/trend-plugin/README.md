# 飞书内个人趋势组件

以当前访问者的飞书权限先读取“项目总表”作品目录，选书后按作品ID及北京时间日期范围筛选“每日数据”，完整读取所选范围后绘图。选书、日期和清空仅在当前组件的 React 内存中，不修改数据、共享切片器或配置。查看者无需编辑项目记录。

- 使用官方 `@lark-base-open/js-sdk`；无服务端、密钥、业务快照或遥测。
- 展示平台、书名和作者；官方ID仅作为内部系列键，同名版本单独保留。
- 原始推荐值按所选作品和日期范围自动设置纵轴，保留边距；未开分、缺失值不补零。
- “一键清空”在当前页面重置所有选择和30天日期，不弹新窗口。
- 源读取失败或分页不完整时显示错误，不用部分记录冒充全量。
- 不自动持久化个人选择，也不修改通知或每日采集流程。
- 首屏仅加载选书界面，飞书 SDK 和按需图表分包；图表库只包含折线图所需模块。
- 日数据查询防抖250毫秒，取消旧请求后不再翻页/显示旧结果；结果仅缓存于当前页60秒（最多20组），刷新数据清空缓存。
- 页面分别显示目录及所选记录的读取耗时，便于区分静态资源、目录、指标三阶段；不上传遥测，不放宽权限。

## 开发与部署

```powershell
npm ci --prefix web/trend-plugin --ignore-scripts
npm test --prefix web/trend-plugin
npm run build --prefix web/trend-plugin
npm run dev --prefix web/trend-plugin
```

只把 `dist/` 作为静态代码部署，严禁加入私有配置/日数据/费用/登录信息。GitHub Pages工作流只上传这个目录。
飞书开发者中心支持根目录 `package.json` 的 `output` 模式。为规避其构建环境版本差异，`python tools/package_trend_hosted.py` 将本机已测试的构建产物复制到 `feishu-dist/`，该目录仅含公开静态代码与哈希。修改组件后先 build 再运行打包命令；CI 校验托管副本与重新构建一致。开发者中心只读取此静态输出，业务数据仍由访问者在飞书内读取；提交发布与 GitHub 推送是两个独立步骤。
飞书“添加组件 → 更多 → 添加自定义插件”填写部署地址，预览后“保存到看板”。首次配置和修改组件需要编辑权限；普通选书/清空不保存共享配置。
上线需实测真实数据完整读取、推荐值两组不同范围、两页隔离、原地清空以及只读账号可用性；构建或单元测试成功不代表这些验证已完成。

2026-11-10现场验证：正式看板已嵌入组件，完整读取3681条每日记录、559个平台作品；两页分别选择白骨小组和盈娘，轴范围独立，一页清空不影响另一页；同名“第十二秒”显示两个中文平台标签并按平台分图。真实只读成员账号尚未代登录验证。组件初始不选书，避免全量曲线堆叠；静态代码更新后浏览器/CDN可能短暂缓存旧资源，排查时核对实际加载的带哈希脚本文件。
