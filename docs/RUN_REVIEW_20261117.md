## 问题与处理

- 主入口和采集子程序直接文件启动的导入缺陷：补隔离进程测试，子采集器执行到快照落盘；失败原文保留，完整快照缺失的来源重新采样。
- v9小清单读入旧v8槽尾部：按有效编号范围缩小前缀，完整有效块及哈希校验保留，旧数据不删除。
- 原位费用调整导致自动汇总变化：核验完整业务表，确认仅预期源字段和对应汇总变化后完成原保护，不重放已成功写入。
- 历史只读对账副本被当作活动未知写入：仅区分有只读收据、与导出清单逐字节一致的副本；真实活动保护、损坏副本和缺失证据仍阻断。原证据全部保留。
- 正常返回不一定业务成功：性能报告新增业务状态，防止把被保护拦截的阶段描述为成功提速。
